# ウイニングロード

three.js による本格競馬シミュレーション。
馬を持ち、仕上げ、使い、引退させ、配合して、次の世代でまた勝負する——
その一周を何十年ぶんでも回せるようにしたブラウザゲーム。

依存パッケージなし。`npm start` で動く。PWA なのでインストールして単独でも遊べる。

```bash
npm start       # http://localhost:8080
npm test        # シミュレーションの検証（84 項目）
```

## 何ができるか

### 馬を育てる

所有馬を厩舎に入れ、9 種類の調教メニューを当てて仕上げる。
坂路はパワーと勝負根性、ウッドチップはスタミナ、コース追いはスピード。
強い調教は速く仕上がるが疲労と故障を呼ぶ。仕上がり・調子・疲労の三つを見ながら、
使うレースから逆算して仕上げていく。

能力は「潜在能力」と「現在値」の二層で、画面に出るのは現在値の評価（A〜G）だけ。
潜在能力は最後まで見えない。走らせてみないと分からない。

### レースに使う

年 48 週、JRA の体系をほぼそのまま置いた番組表。
GI 24 戦を含む重賞 97 競走が実際の時期・競馬場・距離で施行される。
条件戦は開催ごとに手続き的に生成されるので、何十年回しても番組は尽きない。

出走登録では騎手を指名し、脚質（逃げ・先行・差し・追込）を指示できる。
騎手の腕は位置取りの精度に効き、良い騎手は良い馬の取り合いになる。

### 馬を見る

所有馬・セリ市・出馬表には、その馬の毛色のドット絵が並ぶ。
元絵は鹿毛が 1 枚だけで、ほかの 7 毛色は読み込み時にパレットを差し替えて作る。
輪郭線と白斑（流星・靴下）は残し、体と差し毛（たてがみ・尾・管）を
別々の帯へ写すので、陰影の構造を保ったまま色だけが変わる。
芦毛は歳を重ねるごとに白く抜けていく。

### 3D で観る

自分の馬が走る週は、three.js の 3D で観戦できる。
中継カメラ（内馬場を走るカメラ車）、並走、騎手視点、俯瞰、ゴール前の 5 つ。
倍速と巻き戻しができる。

走路は実際の JRA 10 場の 1 周距離・直線距離・高低差から組んでいて、
**レースシミュレーションと 3D は同じ形状データを使っている**。
中山の直線の急坂も、京都の 3 コーナーの下りも、計算と絵で同じ場所にある。

レースの計算は観戦の前に終わっていて、3D は記録された走行ログを再生しているだけ。
だからカメラを変えても早送りしても結果は変わらない。

### 配合する

引退した牝馬は繁殖に上がる。種牡馬を選んで配合する。

- **インブリード** — 5 代までの共通祖先を自動検出する。3×4 がいちばん効き、
  2×3 のような極端な近交は能力より丈夫さと気性を削る
- **ニックス** — 父系 × 母父系の相性。世界生成時に決まっている隠し値で、
  その組み合わせの産駒が 12 頭走って初めて評価が開示される。
  遊んでいるうちに「流行の配合」が自然に生まれる
- **平均への回帰** — 両親の能力はそのまま伝わらない。名馬の仔が凡馬で終わることも、
  無名の牝馬から大物が出ることもある

### 競馬界が勝手に動く

NPC の馬主が 70 人、騎手 110 人、調教師 90 人。
彼らも馬を使い、勝ち、故障し、引退し、配合する。
リーディングが動き、種牡馬の種付料が産駒成績で跳ね上がり、系統が栄枯盛衰する。
年末には年度代表馬が選ばれ、コースレコードが更新されていく。

## シミュレーションの中身

### レース

0.1 秒刻みで全馬の速度・位置・横位置・余力を進める。

- **最高速の差は小さい。** 未勝利馬と GI 馬の時計差は実際の競馬でも 3〜5% しかない。
  勝負を分けるのは「それをどこまで保てるか」＝余力（HP）の設計
- **道中は先頭が決めた速度に全馬が合わせる。** 脚質の違いは
  「先頭から何メートル後ろに居たいか」だけ。逃げ馬が複数いれば競り合ってペースが上がり、
  自然にハイペースになって差し・追込が台頭する
- **先頭は損をする。** 自分でペースを作る馬は余力の消費が 15% 増え、
  後方で我慢した馬は脚が溜まる。この非対称がないと逃げ馬だけが勝ち続ける
- **余力が減ると最高速が連続的に落ちる。** 半分あるうちはほとんど落ちず、
  尽きかけてから一気に効く。階段にすると直線でぴたりと止まる絵になる
- **外を回れば本当に距離を損する。** 内ラチから 5m 外を半径 150m のコーナーで
  回れば、その区間を 3.3% 余計に走る
- **進路は取り合いになる。** 前が詰まれば空いている側へ持ち出す。
  両側が埋まっていれば前の馬に合わせて待つしかない（「前が壁」）

結果として出る時計は実際の JRA の範囲に収まる。

| | 本作 | 実際の目安 |
|---|---|---|
| 東京芝 1600m | 1:30 前後 | 1:31〜1:33 |
| 東京芝 2400m | 2:22 前後 | 2:21〜2:25 |
| 中山芝 1200m | 1:08 前後 | 1:07〜1:08 |
| 京都芝 3200m | 3:12 前後 | 3:12〜3:18 |
| 上がり 3F | 32〜38 秒 | 32〜38 秒 |
| 最下位との着差 | 平均 9 秒 | 5〜10 秒 |

### 競馬界の生成

シードひとつから、血統が 56 年さかのぼれる架空の競馬界を作る。
創始種牡馬 18 頭と繁殖牝馬 140 頭から紙の上で世代を重ね、
現役世代だけを「本物」として走らせる。

サラブレッドの世代間隔は実際に 8〜10 年あるので、5 代血統表を埋めるには
40 年以上の歴史が要る。生成直後で 5 代血統表の 75% が埋まり、
1 頭あたり平均 3 前後のインブリードを持つ。実際の血統表に近い密度になる。

実在の馬は種牡馬・繁殖牝馬と、その系譜の名馬が登場する（それ以外の馬名は生成される）。
競馬場・レース名・施行条件は実在のものに合わせてある。

## 構成

```
index.html          入口

src/sim/            競馬界。DOM を触らない。Node から全部動く

  race.js             レースシミュレーション（0.1 秒刻み）
  horse.js            馬のモデル（能力・適性・成長・気性・故障）
  pedigree.js         血統表・インブリード検出・ニックス
  breeding.js         交配と仔の生成
  schedule.js         年間番組（重賞 97 ＋ 条件戦の生成）
  training.js         調教メニュー
  world.js            世界の生成と週送り
  realsires.js        実在の馬を開始年と史実の年に合わせて世界へ入れる（誕生・輸入・種牡馬入り）
  calendar.js         牧場の年間スケジュール（誕生・種付け・セール・入厩）
  sales.js            各セールの上場馬・値段・購入
  data/real-horses.js 実在の種牡馬・繁殖牝馬・昭和からの名馬と父祖の表（2026 年度の種付料つき）
  game.js             UI から触る唯一の入口
  save.js             セーブ（IndexedDB）
src/render3d/       three.js。走行ログを再生する
  track.js            走路・ラチ・スタンド・遠景
  horse3d.js          馬と騎手。脚の動きは走行距離に同期
  raceview.js         シーン・カメラ・再生
  pasture.js          ホームの背景。放牧地を所有馬が歩き、草を食む
src/ui/             画面
  app.js              殻（上の帯・左のメニュー・NEXT・背景の 3D）
  icons.js            メニューと帯のアイコン（SVG）
assets/             馬のドット絵（元絵と、背景を抜いたスプライト）
vendor/three/       three.js r169（MIT）を同梱
tools/              serve / verify / timecheck / season / icons / sprite
```

## 操作

- `N`（または左下の NEXT）— 次の週へ
- NEXT の長押し（または `Shift+N`）— まとめて週送り。各月の 1 週・行事の始まる週・年末処理まで選べる。
  自分の馬が走る週と年末処理では途中で止まり、その間の自分の馬の出来事をまとめて見せる
- `S`（または NEXT の下のセーブ）— セーブ / ロード
- ホーム右のカードは ↑↓ でめくる（出走予定・重賞・所有馬・先週の結果・強豪・経営）
- 種牡馬は実在（2026 年に日本で供用中の 35 頭と、サンデーサイレンスなどの父祖）。
  種付料は各スタリオンが発表した 2026 年度の額
- 繁殖牝馬にも実在の名牝（アーモンドアイ・ジェンティルドンナ・イクイノックスの母など）がいて、
  牧場の「繁殖牝馬名鑑」から買える。タイトル画面で架空だけの世界も選べる
- 開始年は 2026・2005・1995・1985・1975 年から選べる。昔から始めると、
  ノーザンテーストやサンデーサイレンスが史実の年に輸入され、ミスターシービー・シンボリルドルフ・
  オグリキャップ・ナリタブライアン・ディープインパクトなどが史実の年に史実の父母から生まれる
  （生まれた年の当歳セールに「のちの○○」として並ぶので、買って走らせることもできる）。
  走りはこの世界のレースで決まるので、史実どおりに勝つとは限らない
- 1975〜1980 年代の日本の名馬：シンザン（種牡馬）・カブラヤオー・テスコガビー・ホウヨウボーイ・
  カツラノハイセイコ・ハギノトップレディ・ミホシンザン・ダイナガリバー・サクラスターオー・イナリワン・
  サクラチヨノオー・ヤエノムテキ・アイネスフウジン
- 1990 年代の日本の名馬：ヤマニンゼファー・ニシノフラワー・サクラチトセオー・ノースフライト・ホクトベガ・
  ヒシアマゾン・フサイチコンコルド・シーキングザパール・サニーブライアン・メジロブライト・シルクジャスティス・
  ファレノプシス・メイショウドトウ・アグネスデジタル・アグネスフライト・エアシャカールなど
- 2000 年代の日本の名馬：タップダンスシチー・ファインモーション・ヒシミラクル・デュランダル・スティルインラブ・
  カンパニー・スイープトウショウ・デルタブルース・ハットトリック・ラインクラフト・カネヒキリ・ヴァーミリアン・
  アドマイヤムーン・ディープスカイ・エスポワールシチー・ロジユニヴァース・アンライバルド・レッドディザイア・
  ナカヤマフェスタ・エイシンフラッシュなど
- 2010 年代から令和の日本の名馬：ワンアンドオンリー・イスラボニータ・ミッキークイーン・サトノクラウン・マカヒキ・
  リオンディーズ・アルアイン・ソウルスターリング・ワグネリアン・ブラストワンピース・ラッキーライラック・
  インディチャンプ・ワールドプレミア・アドマイヤマーズ・ウシュバテソーロ・ジェラルディーナ・ジャックドール・
  ソングライン・ナミュール・タスティエーラ・ソールオリエンス・ドゥレッツァ・レガレイラ・チェルヴィニア・
  アスコリピチェーノ・ジャンタルマンタル・アーバンシック・ミュージアムマイル・エンブロイダリー、輸入種牡馬ハービンジャー
- 史実馬は 1970 年代から令和まで（タマモクロス・メジロライアン・ビワハヤヒデ・ウオッカ・
  オルフェーヴル・ドゥラメンテ・タイトルホルダー・クロワデュノールなど）。牝系もつないである
  （ダイナカール → エアグルーヴ → アドマイヤグルーヴ → ドゥラメンテ）
- 配合理論（数値は独自）
  - 因子：名馬はスピード・スタミナ・パワー・瞬発・根性・精神・健康のうち 0〜2 個の因子を持つ。
    3 代までの祖先の因子が仔の能力を少し後押しする。ゲーム中も GI 3 勝以上の馬は引退時に因子を得る
  - 血の活力：父系・母父系・父の母父系・母の母父系が 4 つとも別の系統なら小さく上乗せ、同じ系統を重ねると減点
  - 系統確立：息子が 5 頭以上種牡馬になった馬は「○○系」として独立する（2026 年ならディープインパクト系）
- 海外の名馬：リボー・シーバード・ブリガディアジェラード・ミルリーフ・セクレタリアトから
  フランケル・フライトライン・バーイードまで、海外で供用されていた年に海外種付けができる
  （1975 年なら 10 頭、2026 年なら 13 頭が並ぶ）。ラムタラは 1996 年に日本へ輸入される。
  1975〜1980 年代の名馬（アレッジド・ザミンストレル・アリダー・トロイ・スペクタキュラービッド・シャーガー・
  エルグランセニョール・レファランスポイント・アリシーバ・イージーゴア、名牝アレフランス・ダリア・
  ジェニュインリスク・パーソナルエンスン）も、1 歳の年の海外セールと引退後の海外種付けで関われる。
  フェルディナンド（1986 年のケンタッキーダービー馬）は 1995 年に日本へ輸入される
  1 歳の年の海外トレーニングセールに「のちのフランケル」として上場され、買えば日本で走らせられる。
  海外の名牝（ミエスク・アーバンシー・カインド・ゼニヤッタ・ザルカヴァ・ゴルディコヴァ・ブラックキャビア・
  トレヴ・エネイブル・レイチェルアレクサンドラ・ウィンクス）も、海外で繁殖に上がっている年の同じセールで繁殖牝馬として買える
- 牧場の一年（ホームの「年間」カードと牧場のタブ）
  - 4 月：幼駒の誕生（前年 5〜6 月に種付けした繁殖牝馬が出産）
  - 5〜6 月：種付け（6 月末に受胎が分かる。不受胎なら種付料は返る）
  - 8 月：当歳（0 歳）セール ／ 10 月：繁殖牝馬セール
  - 12 月 3 週：海外トレーニングセール（外国の 1 歳馬・繁殖牝馬）、庭先取引
  - 12 月 4 週：1 歳馬の購入最終チャンス、入厩先（調教師）と馬名の決定
  - 年末処理：表彰式・引退馬・種牡馬と繁殖牝馬の登録・馬名登録・牧場の確認
- 所有馬は現役馬・繁殖牝馬・種牡馬・幼駒の区分からミニアイコンで選ぶ
- 馬の詳細は上のミニアイコンで直接選ぶか、左右スワイプ（または `←` `→`）で同じ区分の次の馬へ送る
